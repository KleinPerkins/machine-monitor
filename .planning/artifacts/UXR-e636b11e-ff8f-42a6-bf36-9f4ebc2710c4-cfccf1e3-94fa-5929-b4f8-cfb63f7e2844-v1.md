# Private update experience

UX-001: Preserve the monitor's dedicated app/window and automatic visible 30-second first scan. Updates do not alter dashboard charts, hover layout or collection leases.
UX-002: Add Check for Updates and Update Settings to the app menu. Settings show installed version, access status, last check and update state before secondary details. Offer Import Access File, Remove Access, Check Now, automatic check/install controls, and Install after scan or Discard when ready.
UX-003: Access import uses a native file picker or explicit document open. Validate the file and remote grant before replacing the Keychain credential. Confirm replacement/removal when existing access would change. Do not display or copy the token. Errors distinguish invalid file, network unavailable, expired/revoked access, verification failure and insufficient install space while keeping monitoring usable.
UX-004: Default automatic checking/download/installation begins only after valid access. Stage safely during a scan; show Update ready — waiting for this scan, then restart only after idle admission. Hidden apps defer disruptive restart. Turning off automatic installation before admission keeps the ready update staged until manual install/discard. Once Installing starts, conflicting actions are disabled with an explicit status.
UX-005: The first-download page explains macOS26+/Apple Silicon, private personal-use terms, selecting an access file, download/unzip/Applications placement and importing the same file once. It exposes no private release list before authorization. Loading, no access, expired/revoked, network error, verifying access, download progress, success and retry are visible states. Credentials stay in browser memory and are cleared on reset/unload.
UX-006: Native controls use AppKit system fonts, semantic colors, labels, tab order, standard keyboard shortcuts and VoiceOver descriptions. Web controls use semantic HTML, visible focus, adequate contrast, descriptive live status and labels; no hover-only information or required animation. Keyboard operation and state announcements are acceptance gates.
UX-007: Native settings are usable at 520x480 and larger with scrollable content when necessary. Web first-download layout covers 360px phone, tablet and desktop without horizontal overflow or moving controls on hover. Respect reduced motion and system appearance.
UX-008: Retain a verified previous application, explain when a restart is imminent, and provide clear recovery guidance. Access and pre-admission update failures preserve monitoring and the known-good app. Unknown admitted-installer ownership intentionally pauses monitoring and presents Recovery until resolved. Do not call updates operational until actual signed private upgrade qualification passes.

UX-009: Include a separate Machine Monitor Recovery app with clear Restore Previous Version and Cancel actions. Explain verified versions and retained backup before restoration. If an interrupted installer cannot be proven finished, instruct the recipient to restart the Mac and open Recovery first; preserve the backup and report the reason. Recovery never starts a scan or changes access preferences. An update-triggered relaunch stays dormant; the next ordinary launch starts its default scan.
